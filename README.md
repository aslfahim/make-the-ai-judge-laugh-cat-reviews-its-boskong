One funny single-line one-star review from a house cat about its human, written
by `main.py` (Python stdlib only) to `/output/entry.txt`.

The concept: **Lazy Door Staff** — the cat gives one star because its human
opens doors far too slowly, making the cat wait like a common guest in its own
house. Deadpan review shape, one star, one complaint, one sting at the end.

Entry for the [make.fun competition](https://make.fun/c/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990).
